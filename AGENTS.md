# AGENTS.md

This file provides guidance to AI agents when working with code in this repository.

## Overview

A kubebuilder (go/v4, multigroup) operator under the `thecluster.io` domain.
Each API group lives in `api/<group>/v1alpha1` with its controllers in `internal/controller/<group>`, and `PROJECT` records every resource kubebuilder scaffolded.

## Tooling

The Nix flake's devshell supplies everything that is not a Go module: `go`, `helm`, and from `unmango/kubepkgs` `kubectl`, `kind`, `kustomize`, and the envtest binaries (`kube-apiserver`, `etcd`, `kubectl`).
The devshell exports `KUBEBUILDER_ASSETS` pointing at those, so `make test` fails fast outside it rather than downloading binaries.
The kubepkgs set is pinned to the Kubernetes minor matching `k8s.io/api` in `go.mod`; bump both together.
Go-only tools (`controller-gen`, `kubebuilder`, `golangci-lint`, `devctl`) are `tool` entries in `go.mod` and run through `go tool`.

```sh
make test               # manifests + generate + vet, then go test with envtest
make lint               # go tool golangci-lint run
make fmt                # nix fmt -> treefmt (gofmt, nixfmt, actionlint, zizmor, deadnix, statix)
make check              # nix flake check, which includes the treefmt check
make manifests generate # after any change under api/
make helm               # regenerate dist/chart from config/
```

## Conventions

- After editing a type under `api/`, run `make manifests generate` and commit the result; CI fails on a diff.
- Register types with `SchemeBuilder.Register(func(s *runtime.Scheme) error { ... })`, the shape kubebuilder 4.16 scaffolds; `controller-runtime/pkg/scheme.Builder` is deprecated.
- `k8s.io/*` modules move together; Renovate groups them and refuses pre-releases.
- `dist/chart` is generated by the kubebuilder helm plugin. Its `values.yaml` survives regeneration, but templates do not.

## Release flow

release-please (`release-please-config.json`, `.release-please-manifest.json`) opens a release PR on every push to `main` and tags `vX.Y.Z` when it merges.
It authenticates as thecluster[bot], so the tag push triggers `main.yml`, which publishes multi-arch images to `ghcr.io/unmango/thecluster-operator`.
The release PR also bumps `version` and `appVersion` in `dist/chart/Chart.yaml`; never hand-edit them or `CHANGELOG.md`.
PRs land as squash merges and `pr-title.yml` enforces a Conventional Commit title, since that title is what release-please reads.

## CI

- Checks run on the self-hosted `thecluster` runners, whose image ships nix; jobs run inside `nix develop`.
- Image publishing stays on GitHub-hosted runners because the arm64 build is emulated.
- Action versions are pinned to commit SHAs with a trailing `# vN` comment, updated by Renovate.
